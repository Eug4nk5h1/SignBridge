# ISL Isolated 40-Words Dataset Metadata & Provenance

## Dataset Overview
* **Dataset Name:** Indian Sign Language (ISL) Isolated 40-Words Dataset
* **Source:** Hugging Face Dataset Repository (`vidit031/isl-isolated-40words`)
* **Hugging Face URL:** https://huggingface.co/datasets/vidit031/isl-isolated-40words
* **Source Snapshot Hash:** `255ce7fd10da5d05bc30d59668ba256e5f02531c`
* **Local Integration Path:** `dataset/isl_40words/`

## Dataset Contents
* **Total Words / Vocabulary Size:** 40 isolated ISL words
* **Total Video Clips:** 642 MP4 video files
* **File Structure:** Organised by word/gloss subdirectories (`dataset/isl_40words/<word>/`). Each folder contains a primary clip (`<word>.mp4`) and additional sample variations (`<word>_clip_02.mp4`, etc.).
